# DomiVass — instaladores

**DomiVass**, o clube do dominó da Universidade de Vassouras. Desenvolvido por **BomBista Games**.

## Como instalar

1. Abra a página de [Releases](../../releases/latest) e baixe o arquivo `DomiVass-Setup-x.y.z.exe` da versão mais recente.
2. Execute o instalador. Ele instala o jogo só para o seu usuário, sem pedir senha de administrador
   (a não ser que o Windows precise dos componentes do Visual C++, só na primeira vez).
3. Abra o **DomiVass** pelo atalho e entre com a sua matrícula ou e-mail.

O jogo se atualiza sozinho: ao abrir, ele confere se há uma versão nova, baixa e instala.

Requisitos: Windows 10 ou 11 de 64 bits, internet.

Este repositório guarda só os instaladores; o código do jogo fica em outro repositório.
