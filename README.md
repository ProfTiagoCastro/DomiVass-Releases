# DomiVass — instaladores

**DomiVass**, o clube do dominó da Universidade de Vassouras. Desenvolvido por **BomBista Games**.

## Como instalar

1. Abra a página de [Releases](../../releases/latest) e baixe o arquivo `DomiVass-Setup-x.y.z.exe` da versão mais recente.
2. Execute o instalador e siga os passos (dá para escolher a pasta). Ele instala o jogo só para o seu usuário, sem pedir
   senha de administrador (a não ser que o Windows precise dos componentes do Visual C++, só na primeira vez).
3. Se o Windows mostrar **"O Windows protegeu o computador"**, clique em **Mais informações** e depois em
   **Executar assim mesmo**. O aviso aparece porque o instalador ainda não tem assinatura digital; o jogo é seguro.
4. Abra o **DomiVass** pelo atalho e entre com a sua matrícula ou e-mail.

Depois disso o jogo se atualiza sozinho: ao abrir, ele confere se há uma versão nova e baixa só o que mudou.

Requisitos: Windows 10 ou 11 de 64 bits, internet.

Este repositório guarda só os instaladores; o código do jogo fica em outro repositório.
